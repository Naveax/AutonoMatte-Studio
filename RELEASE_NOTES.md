# AutonoMatte Studio 0.6.1

## Paketleme değişiklikleri

- Ürün adı: **AutonoMatte Studio**
- Önerilen GitHub repository adı: **AutonoMatte-Studio**
- Windows'ta kullanıcı için tek çalıştırma dosyası: `AutonoMatte.bat`
- Kurulum, çalıştırma, model taşıma, sistem testi ve GitHub hazırlama tek launcher içinde birleştirildi.
- Uygulama kaynakları `.app`, modeller `.models`, runtime `.runtime` altında izole edildi.
- Model dosyaları için Git LFS kuralları eklendi.
- GitHub Actions temel test akışı eklendi.
